# LeRobot视觉识别与Python编程课程

## 课程概述

本课程将Python编程与LeRobot视觉识别技术相结合，为学生提供一个从基础编程到AI视觉识别再到机器人控制的完整学习体验。课程专为小学4-6年级学生设计，通过有趣的项目实践，让学生掌握现代AI技术的基础知识。

## 课程目标

1. **编程技能**：掌握Python基础语法和编程思维
2. **AI技术**：理解计算机视觉和机器学习基本概念
3. **机器人控制**：学会控制机械臂进行简单操作
4. **创新思维**：培养解决问题和创新思考的能力

## 课程结构

- [第一阶段：Python基础与LeRobot初探](./level-1/)
- [第二阶段：LeRobot视觉识别进阶](./level-2/)
- [第三阶段：机械臂控制与交互](./level-3/)
- [第四阶段：情感交互机器人开发](./level-4/)

## 学习成果

完成本课程后，学生将能够：
- 独立编写Python程序
- 使用LeRobot进行视觉识别
- 控制机械臂执行简单任务
- 开发桌面陪伴机器人原型
- 理解AI与机器人技术的基本原理
